פירוק לגורמים ומשוואות ריבועיות

דף לימוד ותרגול לקראת כיתה י'. קראו את ההסברים, עברו על הדוגמאות, ואחר כך פתרו את התרגילים בסוף הדף.

חלק א: מה זה פירוק לגורמים

פירוק לגורמים הוא כתיבה של ביטוי אלגברי כמכפלה של ביטויים פשוטים יותר. זה ההפך מפתיחת סוגריים: בפתיחת סוגריים הופכים מכפלה לסכום, ובפירוק הופכים סכום למכפלה. למשל, 3(x + 4) = 3x + 12 היא פתיחת סוגריים. הכיוון ההפוך, מ־3x + 12 אל 3(x + 4), הוא הפירוק.

למה זה חשוב? כי מכפלה קל לאפס: מכפלה שווה לאפס רק כאשר אחד הגורמים שלה שווה לאפס. על העובדה הזו בנוי הפתרון של משוואות ריבועיות בחלק ה.

חלק ב: הוצאת גורם משותף

השלב הראשון בכל פירוק הוא לחפש גורם שמופיע בכל האיברים, ולהוציא אותו מחוץ לסוגריים. כדאי להוציא את הגורם המשותף הגדול ביותר.

דוגמה 1: 6x + 9 = 3(2x + 3), כי 3 מחלק גם את 6 וגם את .9 דוגמה 2: 4x² − 8x = 4x(x − 2). הגורם המשותף כאן הוא 4x, ולא רק .4

בדיקה: פותחים את הסוגריים בחזרה. אם מקבלים את הביטוי המקורי, הפירוק נכון.

חלק ג: נוסחאות הכפל המקוצר

שלוש נוסחאות שימושיות במיוחד בפירוק:

1. הפרש ריבועים: a² − b² = (a − b)(a + b) 2. ריבוע של סכום: (a + b)² = a² + 2ab + b² 3. ריבוע של הפרש: (a − b)² = a² − 2ab + b² דוגמה 3: x² − 49 = (x − 7)(x + 7), כי 49 = 7².

דוגמה 4: 9x² − 25 = (3x − 5)(3x + 5), כי 9x² = (3x)² ו־25 = 5². דוגמה 5: x² + 10x + 25 = (x + 5)², כי האיבר האמצעי הוא 2·x·5 = 10x.

שימו לב: הפרש ריבועים עובד רק כשיש מינוס בין שני הריבועים. הביטוי x² + 9 הוא סכום ריבועים, ואי אפשר לפרק אותו בעזרת הנוסחה הזו.

חלק ד: פירוק טרינום

טרינום הוא ביטוי בעל שלושה איברים מהצורה x² + bx + c. כדי לפרק אותו מחפשים שני מספרים שהמכפלה שלהם היא c והסכום שלהם הוא .b דוגמה 6: x² + 5x + 6. מחפשים מכפלה 6 וסכום 5: המספרים הם 2 ו־3. לכן .x² + 5x + 6 = (x + 2)(x + 3) דוגמה 7: x² − x − 12. מחפשים מכפלה −12 וסכום −1: המספרים הם −4 ו־3. לכן .x² − x − 12 = (x − 4)(x + 3) בדיקה לדוגמה 7: (−4)·3 = −12 וגם −4 + 3 = −1.

כלל לזכור: הסכום של שני המספרים שווה למקדם של x, עם אותו סימן בדיוק. בדוגמה 7 המקדם הוא −1, והסכום הוא −1.

חלק ה: פירוק מלא

פירוק מלא פירושו שאי אפשר להמשיך לפרק אף אחד מהגורמים. הסדר הנכון: קודם מוציאים גורם משותף, ואחר כך בודקים אם מה שנשאר בסוגריים אפשר לפרק עוד. דוגמה 8: 2x² − 18 = 2(x² − 9) = 2(x − 3)(x + 3).

הביטוי 2(x² − 9) נכון, אבל הוא עדיין לא פירוק מלא, כי x² − 9 הוא הפרש ריבועים.

חלק ו: פתרון משוואה ריבועית בעזרת פירוק

משוואה ריבועית היא משוואה מהצורה ax² + bx + c = 0. כשאפשר לפרק את האגף השמאלי, משתמשים בכלל: אם מכפלה שווה לאפס, אחד הגורמים שווה לאפס.

דוגמה 9: x² − 5x + 6 = 0 1. מפרקים: (x − 2)(x − 3) = 0 2. משווים כל גורם לאפס: x − 2 = 0 או x − 3 = 0 3. הפתרונות: x = 2 או x = 3

טעות נפוצה: במשוואה x² = 3x מחלקים את שני האגפים ב־x ומקבלים רק x = 3. כך הולך לאיבוד הפתרון x = 0. הדרך הנכונה היא להעביר אגף ולפרק: x² − 3x = 0, כלומר x(x − 3) = 0, ולכן x = 0 או x = 3.

חלק ז: נוסחת השורשים והדיסקרימיננטה

כשהפירוק לא קל, משתמשים בנוסחת השורשים: x = (−b ± √(b² − 4ac)) / 2a הביטוי שמתחת לשורש נקרא דיסקרימיננטה: Δ = b² − 4ac. הוא קובע כמה פתרונות יש למשוואה: 1. אם הדיסקרימיננטה חיובית, יש שני פתרונות. 2. אם הדיסקרימיננטה שווה לאפס, יש פתרון אחד. 3. אם הדיסקרימיננטה שלילית, אין פתרון.

דוגמה 10: 2x² + 3x − 2 = 0. כאן a = 2, b = 3, c = −2. 1. מחשבים את הדיסקרימיננטה: Δ = 3² − 4·2·(−2) = 9 + 16 = 25 2. מציבים בנוסחה: x = (−3 ± 5) / 4 3. הפתרונות: x = 0.5 או x = −2 בדיקה: 2·(0.5)² + 3·0.5 − 2 = 0.5 + 1.5 − 2 = 0.
